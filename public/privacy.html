XR-ACP Companion プライバシーポリシー / Privacy Policy

最終更新日 / Last Updated: 2026-11-21

1. ローカルファースト設計（データ収集なし）

XR-ACP Companion はユーザー自身が管理するローカル環境（Termux 等）またはプライベートネットワーク（Tailscale 等）上の ACP ブリッジへ直接接続するクライアントです。開発者サーバーへのテレメトリ、広告トラッキング、分析データの送信は一切行いません。

2. 端末内に保存される情報

  • 接続プロファイル（接続先 URL、エージェント選択、光学テーマ設定、認証トークン）はブラウザの localStorage にのみ保存されます。
  • セッション履歴キャッシュはブラウザの IndexedDB（または localStorage）にのみ保存され、アプリ内の「履歴 → 全履歴を削除」からいつでも消去できます。

3. マイク（音声入力）の利用

Push-to-Talk 音声入力機能を使用した場合のみ、ブラウザ標準の Web Speech API を通じて音声をテキストへ変換し入力欄へ反映します。 音声データは本アプリ側で録音・保存・第三者送信しません。

4. 外部通信

オフラインデモモードでは外部通信を行いません。ブリッジ接続時は、ユーザーが明示的に指定した接続先（例: 127.0.0.1 または任意の Tailscale IP）とのみ WebSocket / HTTP 通信を行います。

Summary (English)

XR-ACP Companion is a local-first Agent Client Protocol (ACP v1) companion app. It collects zero telemetry, zero analytics, and sends no data to developer-operated servers. Connection profiles and cached conversation history are stored solely on-device in browser storage. Microphone access is optional and used only via the browser's Web Speech API when Push-to-Talk voice input is actively toggled by the user.
