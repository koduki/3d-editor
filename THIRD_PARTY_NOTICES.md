## 1. Separate Executables & Bundled Runtime Archives (Process-Isolated Aggregate)

The components below are executed as separate child processes via `ProcessBuilder` (`execve`) and communicate with the Android host strictly over local HTTP/WebSocket or standard I/O. They are not linked into the KuCode Android/JVM application code.

  - **Upstream License:** GNU General Public License v2.0 or later (`GPL-2.0-or-later`, see `LICENSES/GPL-2.0.txt` and `LICENSES/GPL-3.0.txt`)
- **Samba talloc Upstream:** https://talloc.samba.org/ (`talloc-2.5.0`)
  - **Copyright:** Copyright (C) Andrew Tridgell and Samba Team contributors
  - **Upstream License:** GNU Lesser General Public License v3.0 or later (`LGPL-3.0-or-later`, see `LICENSES/LGPL-3.0.txt`)
- **Effective Combined License of Distributed Binaries:**
  - `lib/arm64-v8a/libproot.so` (PRoot statically linked with `libtalloc.a`): **`GPL-3.0-or-later`**
  - `lib/arm64-v8a/libproot-loader.so` (unbundled PRoot loader): **`GPL-2.0-or-later`**
- **Modifications Made (GPL §5(a) Notice):**
  - On 2026-11-22, `scripts/build-proot-android.sh` applies a 1-line compatibility patch to `src/extension/ashmem_memfd/ashmem_memfd.c` prepending `#include <string.h>` so that Android NDK r27+ Clang compiles without implicit declaration errors for `strcmp`/`memset`.
  - On 2026-11-24, `scripts/build-proot-android.sh` patches `src/GNUmakefile` (`-z,noexecstack` → `-z,noexecstack,-z,max-page-size=16384,-z,common-page-size=16384`) so that the unbundled `libproot-loader.so` ELF `LOAD` segments are 16KB page-aligned alongside `libproot.so` for Android 15+ devices.
  - Both binaries are cross-compiled for `arm64-v8a` with `-Wl,-z,max-page-size=16384,-z,common-page-size=16384` and `PROOT_UNBUNDLE_LOADER` via `scripts/build-proot-android.sh`.

## 3. Corresponding Source Code & Written Offer (GPL / LGPL Compliance)

In accordance with GNU GPL v2 (§3), GNU GPL v3 (§6), and GNU LGPL v3 (§4), the complete Corresponding Source for all GPL/LGPL binaries distributed in KuCode APK builds is available as follows:

1. **PRoot + Samba talloc (`libproot.so`, `libproot-loader.so`):**
   - Exact source archives, 1-line patch, and reproducible cross-compilation script:
     - Build script & patch: `scripts/build-proot-android.sh` in https://github.com/koduki/kucode
     - PRoot source tag: `https://github.com/termux/proot/archive/refs/tags/v5.1.107.102.tar.gz`
     - Samba talloc source: `https://www.samba.org/ftp/talloc/talloc-2.5.0.tar.gz`
2. **Debian `bookworm-slim` (`arm64`) packages:**
   - The exact binary and source package names and versions bundled in each APK are recorded in `assets/licenses/debian-manifest.txt` (and attached to GitHub Releases).
   - Matching Debian source packages (`.dsc`, `.orig.tar.*`, `.debian.tar.*`) can be retrieved from Debian's official archive (`https://snapshot.debian.org/package/<source_package>/<source_version>/` or `apt-get source <package>=<version>`).
3. **Three-Year Written Offer:**
   - For at least **three (3) years** following the distribution of any KuCode binary release, upon request via a GitHub Issue at https://github.com/koduki/kucode/issues (specifying the APK version / release tag), the project maintainer will provide a complete, machine-readable copy of the Corresponding Source code (including patches and build scripts) for all bundled GPL/LGPL components at no charge via electronic download (or for no more than the physical cost of distribution).
